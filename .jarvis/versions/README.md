# Versões da constituição

Cada decisão adotada gera uma nova versão de `.jarvis/constitution.md` e uma
cópia textual idêntica nesta pasta, conforme o
[procedimento de ADRs](../../docs/adr/README.md).

As cópias preservam o texto e os estados de confirmação existentes em cada
versão. São arquivos de texto para consulta histórica; os caminhos escritos
neles pertencem ao contexto do arquivo original em `.jarvis/`.
Para navegar pela documentação atual, use a
[constituição vigente](../constitution.md).
